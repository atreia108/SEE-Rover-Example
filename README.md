# SEE HLA Starter Kit Lunar Rover Example

A port of the lunar rover example originally written by the SMASH Lab at the University of Calabria as a tutorial for v1.0 of the SEE HLA Starter Kit Framework (SKF). This rewritten version carries the same spirit and showcases how a very simple lunar rover simulation can be created with v2.0 of the SKF.

The example was created using the [SEE Starter Project](https://www.github.com/atreia108/SEE-Starter-Project) as the base. The same instructions for building that project and getting it up and running apply here as well.
